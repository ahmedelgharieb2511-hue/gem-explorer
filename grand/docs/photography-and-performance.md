# الصور والخطوط وLCP

الهوية الحالية: رملي `#F7F1E5`، كحلي `#112A3B`، لازورد `#143C61`، ذهبي `#C49A43`، ونص ذهبي داكن `#805B18`. النص الأساسي 16px إنجليزي و17px عربي، والوصف 16–18px. Cairo وManrope مستضافان محليًا.

## استبدال الصور

حدّث [سجل المصادر](../src/features/artifacts/photo-credits.json) والبيانات والنصوص البديلة أولًا. تحقّق من موضوع الصورة وترخيصها ومجموعتها المرجعية. الصور التعليمية ليست ادعاءً بأن كل القطع موجودة في GEM.

```sh
node scripts/fetch-photographs.mjs
node scripts/optimize-photographs.mjs
```

الأمر الأول ينزّل الصور الناقصة فقط مع التمهل بين الطلبات. الثاني يولد WebP بعروض 480 و768 و1200 دون تكبير الأصل ويحدّث [ملف الأحجام](../src/features/artifacts/photo-variants.json). احفظ الصور وملف الأحجام في المستودع؛ البناء لا ينزلها مجددًا.

## التحميل والأداء

- [ResponsivePhotograph](../src/components/shared/responsive-photograph.tsx) يستخدم صورًا محلية مضغوطة مسبقًا؛ لا تحويل عند أول زيارة.
- صورة المقدمة في HTML الأول من السيرفر، مع `loading=eager` و`fetchPriority=high` و`srcSet/sizes` مناسبين.
- الخلفية الزخرفية تستخدم نسخة أصغر وأولوية منخفضة، وباقي الصور lazy وفق موضعها.
- لا تضف preload لكل الصور والخطوط؛ كثرة الموارد ذات الأولوية العالية تخلق منافسة.
- [SiteLink](../src/components/ui/site-link.tsx) يعطل prefetch التلقائي لصفحات الوجهات. هذا يعالج CSS المحمل مسبقًا لصفحات لم تُفتح.
- اختبار المتصفح ينتظر فترة التحذير ويتحقق من عدم وجود style preloads غير مستخدمة، ومن تحميل صورة المقدمة بصيغة WebP وأولوية عالية.

## إعادة قياس LCP

بعد `npm run build` ثم `npm start`:

```sh
node scripts/measure-lcp.mjs http://127.0.0.1:3000/en
node scripts/measure-lcp.mjs http://127.0.0.1:3000/en --throttled
```

ثلاث زيارات بسياقات متصفح جديدة، ونافذة 1440×1000، ثم وسيط النتائج. الوضع المقيد يحاكي latency 150ms، تنزيل 1.6Mbps، رفع 750Kbps، وCPU أبطأ 4 مرات. القياسات مختبرية محلية؛ قارن بنفس الكاش والشبكة والتقييد ولا تعتبرها ضمانًا لنتائج أجهزة أخرى أو للإنتاج العام.
