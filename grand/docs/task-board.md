# GEM Hackathon — حالة التنفيذ

`[x]` منفذ في الكود/موثق ويمكن تشغيله. `[ ]` يحتاج موردًا خارجيًا أو عملًا لم يتم بعد. نجاح الواجهة التجريبية لا يعني ربط الخدمة الحقيقية.

## Sprint 1 — Design

- [x] User Flow كامل موثق بـMermaid.
- [x] Wireframes وصفية لكل الشاشات والاتجاهين.
- [x] Design tokens ومكونات أساسية قابلة للتعديل.
- [x] تنفيذ تصميم مبدئي متجاوب للشاشات في الكود.
- [ ] اعتماد التنسيق النهائي الذي سيرسله صاحب المشروع.
- [ ] رسم الشاشات داخل ملف Figma أصلي.
- [ ] ربط prototype داخل Figma وتسليم رابطه.

## Sprint 2 — Setup

- [x] Next.js + React + TypeScript + Tailwind CSS.
- [x] الهيكل المطلوب `app/[locale]` وFeature-Based Architecture.
- [x] Navbar وFooter وLayout ومكونات UI مشتركة.
- [x] Routing لكل الصفحات والتفاصيل ومعالجة المسارات غير المعروفة.
- [x] API client وبيئة تشغيل نموذجية.
- [x] ملفات ترجمة مركزية وnamespaces وRTL/LTR.

## Sprint 3 — Core features

- [x] Home متجاوبة.
- [x] كتالوج تجريبي ببحث وفلاتر وترقيم محفوظ في URL.
- [x] صفحة تفاصيل وقصة وحقائق لكل قطعة.
- [x] نموذج الجولة بالوقت والاهتمامات وإتاحة الحركة.
- [x] ترتيب محطات ضمن الوقت يشمل المشي والعودة.
- [x] خريطة SVG توضيحية لدورين ومسار وقائمة بديلة بالكيبورد.
- [x] QR حقيقي لروابط تفاصيل القطع مع تنزيل ونسخ.
- [x] Language switcher يحافظ على الصفحة والاستعلام.
- [ ] استبدال الأمثلة بمخزون وخريطة رسمية معتمدة.
- [ ] تتبع موقع حقيقي داخل المتحف — خارج النموذج الحالي.

## Sprint 4 — Supporting features

- [x] رفع صورة وكاميرا الجهاز ومعاينة والتحقق من الصيغة والحجم.
- [x] شكل نتائج التعرف ودرجة الثقة للخدمة الحقيقية وقطع مرتبطة.
- [x] مثال صريح لا يدعي تشغيل AI.
- [x] فحص VIP من السيرفر ومشغل أصلي ونص تسجيل عند السماح.
- [x] عينة نطق مجانية منفصلة عن VIP.
- [x] Educational Quest من ثلاثة أسئلة مع حفظ تقدم محلي.
- [x] Visitor Feedback بتحقق وموافقة وإيصال لا يدعي حفظ Demo.
- [x] Services وSafety وAccessibility UI.
- [ ] خدمة AI حقيقية وتسجيلات صوت مرخصة.

## Sprint 5 — Quality & delivery

- [x] BFF يمرر الطلبات إلى Backend قابل للتهيئة بعقد موثق.
- [x] Zod للمدخلات والردود، حدود جسم الطلب وفحص توقيع الصورة.
- [x] Loading وError وEmpty states وإعادة المحاولة.
- [x] VIP مبني على رد السيرفر؛ لا فتح محلي للصلاحية.
- [x] تقسيم الصفحات وتحميل QR عند الطلب وصور WebP محلية بأحجام متجاوبة.
- [x] اختبارات للخوارزمية وAPI والترجمات ورحلة الزائر.
- [x] إعداد CI وبناء إنتاج وإرشادات تشغيل ونشر.
- [ ] ربط واختبار Backend الفريق الحقيقي والمصادقة وقاعدة البيانات.
- [ ] نشر رابط عام على حساب استضافة متاح للفريق.
- [ ] مراجعة المحتوى الرسمي والتباين وقارئ الشاشة مع الفريق قبل الإطلاق.
