# Deployment & Hackathon demo

## الوضع الحالي

المشروع يعمل محليًا ويبني نسخة إنتاج. الكود متاح في [مستودع GitHub العام](https://github.com/ahmedelgharieb2511-hue/gem-explorer). استضافة الموقع نفسه على نطاق عام لم تتم بعد؛ الخطوات التالية تجهز نشر التطبيق على حساب استضافة الفريق.

## Vercel

1. ارفع المشروع إلى مستودع فريقك دون ملفات البيئة أو `node_modules` أو `.next`.
2. أنشئ مشروع Next.js واضبط **Root Directory = `grand`** إذا رفعت المجلد الأب كله.
3. Node.js 22 أو أحدث، install `npm ci`، build `npm run build`. لا تضع Output Directory يدويًا.
4. للديمو: اضبط `NEXT_PUBLIC_DATA_MODE=demo`، و`NEXT_PUBLIC_SITE_URL` إلى النطاق النهائي.
5. للتكامل: اضبط `NEXT_PUBLIC_DATA_MODE=api` و`BACKEND_API_URL` الخادمي إلى خدمة الفريق المتاحة عبر HTTPS. لا تستخدم `localhost` لخدمة منشورة.
6. أعد النشر بعد تغيير متغيرات `NEXT_PUBLIC_*`.
7. افحص `/api/health` واللغتين ورابط قطعة مباشر، ثم جرّب إرسال الجولة والتقييم على النطاق المنشور.

على أي منصة Node أخرى: `npm ci` ثم `npm run build` ثم `npm start`. اضبط `PORT` إذا تطلبت المنصة ذلك. استخدم HTTPS في النشر الحقيقي. لا تستخدم static export لأن التطبيق يحتوي Route Handlers لفحص المدخلات والتكامل.

## الجاهزية لخدمة حقيقية

- Backend وقاعدة بيانات وAI endpoints مطابقة لـ[العقد](./api-contract.md).
- جلسة حقيقية لتأكيد VIP؛ التسجيلات نفسها محمية بروابط قصيرة الصلاحية أو خدمة وسائط موثقة.
- صور وبيانات قطع وخريطة قاعات معتمدة ومسموح استخدامها.
- سياسة خصوصية وحفظ للصور والتقييمات، وحدود طلبات ومراقبة أخطاء في Backend.
- اعتماد التصميم وملف Figma واختبار المحتوى العربي والإنجليزي.
- Metadata الحالية تحمل `noindex` لأن البيانات تجريبية. غيّرها بعد اعتماد الإطلاق الحقيقي فقط.

## العرض في خمس دقائق

1. افتح Home وبدّل اللغة؛ أوضح أن الهوية قابلة للتعديل.
2. ابحث عن `gold` أو `ذهب`، افتح القناع، واعرض القصة والـQR.
3. خطط لجولة 30 دقيقة مع مسار ميسر، وافتح خريطة المحطات.
4. افتح Scan؛ اعرض مثالًا مع إقرار عدم تشغيل AI. كاميرا الهاتف أو رفع الصورة يمران بالتحقق نفسه عند تأكيد الطلب.
5. اعرض قفل VIP وعينة المتصفح المجانية؛ لا تستخدمها كادعاء لتسجيل رسمي.
6. أكمل التحدي التعليمي وأرسل تقييمًا تجريبيًا؛ الإيصال يذكر صراحة أنه لم يحفظه.

QR الذي يشير إلى `localhost` لا يفتح الموقع على هاتف آخر. للعرض على عدة أجهزة استخدم رابط نشر يمكن الوصول إليه. افتح العرض مسبقًا وتحقق من الشبكة والمتصفح والصوت دون الاعتماد على عمل API خارجي غير متاح.

## CI

Workflow المشروع يثبت الاعتماديات من lockfile، ويفحص الأنواع والاختبارات ويبني الإنتاج ويشغّل اختبارات Chromium. النشر التلقائي يعتمد ربط المنصة بالمستودع وضبطها لانتظار نجاح الفحوصات؛ لا توجد بيانات دخول أو رموز نشر مضمنة.
